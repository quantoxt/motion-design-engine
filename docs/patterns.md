# Motion patterns

## Pattern A — Product reel (default)
20s, 60fps, 9:16 first. Energy of a showreel. Structure: hook → product assembles →
3 feature moments (cursor drives) → 1 proof number → logo lockup + CTA.
Full spec: `_raw/quantoxt-inc-solo.md`. Route A (single index.html + seek(t)).

## Pattern B — Educational long-form
75-90s, 24fps, 1920x1080 with captions. Teach ONE cause-and-effect relationship
through story, not facts. Needs voiceover (ElevenLabs key in .env, 125-145 wpm).

### World
Torn paper, dry gouache, crayon, pencil texture. Coral, mustard, teal, cream,
charcoal + soft cardboard shadows. Stop-motion boil: shapes shift 1-2px every few
frames (seeded, deterministic — still pure seek(t)).
One mascot narrator; lock silhouette, eyes, scale, proportions (character sheet first).

### Seven scenes
Hook → familiar world → disruption → mechanism → discovery → consequence → recap.
Every scene must add new understanding. One primary visual idea per shot;
key transformations breathe.

### Per scene, specify
- Learning purpose (exact idea taught)
- Visual (composition, characters, objects, labels, camera)
- Motion (entrance, primary action, secondary reaction, exit)
- Voiceover (final spoken line, written for timing)
- Sound (music cue, ambience, synced tactile effects)
- Transition (the visible object that physically becomes the next scene)

### Narration rules
- Concrete language before technical terms.
- Never duplicate narration in on-screen text. Labels brief.
- Warm, precise, playful in presentation, rigorous about clarity.

### Delivery checklist
Concept → visual system → character sheet → timestamped storyboard →
final voiceover → transition map → sound plan → technical implementation →
complete build. Never stop at a mood board or partial prototype.

### Gates (same as Pattern A — non-negotiable)
Shotlist on beat grid → OK → contact sheet + strips → critique 4 rounds (8+) → full render.
Educational adds: voiceover timing pass (animatic at low res before polish).
